# ktmdb

**4KTMDB Player** —— 一个面向 Android TV 与 Android 手机的影视播放客户端，支持遥控器操作、字幕渲染、弹幕、本地离线播放与片库浏览。

> 本仓库暂不开源，仅作为项目入口与官网链接使用。

## 下载与官网

| | |
|---|---|
| 官网 | <https://ktmdb.genesis4k.com/> |
| 直接下载 | <https://ktmdb.genesis4k.com/fdroid/repo/ktmdb-0.10.apk> |
| F-Droid 自建仓库 | <https://ktmdb.genesis4k.com/fdroid/repo> |

在 F-Droid 客户端中添加上述仓库地址，即可跟进后续版本更新（应用包名 `com.genesis4k.ktmdb.player`）。

## 系统要求

- Android 5.0（API 21）及以上
- 架构：arm64-v8a / armeabi-v7a / x86 / x86_64
- 电视端建议使用遥控器操作，支持「简单模式」快捷键

## 说明

本站不存储、不制作任何视频内容，仅提供播放器客户端与个人片库管理能力。所有内容来源由用户自行配置，使用时请遵守当地法律法规与内容提供方的服务条款。
