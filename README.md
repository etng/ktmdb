# ktmdb

**4KTMDB Player** —— 面向 Android TV 与 Android 手机的影视客户端。

## 我们想解决的事

- **不用 NAS，不用堆硬盘。** 片源在服务端，客户端只负责播。不买设备、不整理文件、不养一块盘。
- **编辑严选，谢绝低质量片源。** 画质、码率、音轨、字幕逐部过一遍，不达标的不上架。
- **高清带字幕。** 4K / 1080p 高清，中文字幕随片自带，不用自己满网找字幕文件。
- **手机电视同步看。** 手机上看一半，回客厅按一下接着放。
- **不多花钱。** 不订阅、不按部收费。

## 官网

<https://ktmdb.genesis4k.com/>

在 F-Droid 客户端中添加 <https://ktmdb.genesis4k.com/fdroid/repo> 即可获取后续更新（应用包名 `com.genesis4k.ktmdb.player`）。

## 系统要求

- Android 5.0（API 21）及以上
- 架构：arm64-v8a / armeabi-v7a / x86 / x86_64
- 电视端建议使用遥控器操作，支持「简单模式」快捷键

## 说明

本站不存储、不制作任何视频内容，仅提供播放器客户端。内容来源由服务端配置，使用时请遵守当地法律法规与内容提供方的服务条款。
